Arcturus, the 1984 Ada interpreter

UC Irvine's interactive Ada environment, release 1.6-A as linked on January 5, 1984. The original C was compiled to WebAssembly and runs in your browser, with nothing on a server.

Script pad

      
Write several lines, then type them into the session as if you'd typed each one.

      
      

    

    

      
How it reads you

      

        
x := 3;
A line ending in ; is a declaration or statement. Assigning an undeclared name declares it.

        
x * 6
No ; means an expression, and its value is printed.

        
+
The prompt for the next line of an unfinished declaration.

        
:
The prompt in an error break. Look around, then press ^D to leave it.

        
pp(f'sym);
Prettyprints a declaration.

        
dir;
Lists what you have declared.

        
where;
Shows the current scope.

        
symbol_table;
Dumps the symbol tables.

        
↑ ↓
Recall earlier lines.

      

    

  


  

    

      
What you're running

      
Arcturus was built at the Irvine Programming Environment Project in 1982–84 under Professor Thomas A. Standish, with DARPA support. It interprets Ada as you type it, keeps a live symbol table, and lets you inspect and prettyprint whatever you've declared.

      
The release here was recovered from a 1980s backup tape in 2026. Two missing files, the evaluator int.c and the main loop toplev.c, were rebuilt line-exact from the VAX binary.

    

    

      
How it runs here

      
The ported 1984 C sources are compiled with clang to WebAssembly, against wasi-libc. Arcturus's error recovery uses setjmp and longjmp, which become WebAssembly exceptions. Its run-time Ada files sit in a small in-memory file system.

      
Each line you enter replays the session from the start in a fresh interpreter. That takes a few milliseconds and keeps every run exactly reproducible. A line that crashes or runs for more than 8 seconds is dropped.

    

    

      
Limits it had in 1984

      
Record aggregates are unimplemented, and tasks and generics print "You've used an unimplemented construct". Integers are 32 bits. Saving a memory image, loading VAX object files and calling an editor can't work here.
